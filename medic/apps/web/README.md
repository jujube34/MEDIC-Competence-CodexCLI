应用 API 启动后访问 `http://127.0.0.1:8765/`。启动与合成账号初始化见 [API 说明](../api/README.md)。这是同一服务提供的静态网页，身份和授权来自后端，不能在浏览器切换一个角色名称来获得权限。

- 员工：上传 PDF/Office 文件、检查原文与质量缺口、选择同周期材料和固定标准范围，创建预评估，查看结果。
- 上级：在明确授权的员工范围中逐项复核，引用原文、记录理由、补充人工观察，核验风险后定稿。
- 医学总监：默认显示授权范围概览，可进入获授权评估的证据与复核；不自动扩大员工范围，不对员工排名。

岗位推荐、AI 建议、人工判断分别展示。非评分项与缺分保留空值。结果页展示五维和 17 项能力对照；未纳入范围与范围内缺失档位分别提示。五维仅在该维度全部能力项有值时显示档位序号均值，始终展示范围与人工评分覆盖率；序号不被解释为等距能力值。AI 和人工引用可跳转并高亮对应不可变原文块，服务端重新检查范围、原文件与引用 hash。原件通过带认证的下载请求取得。

定稿后隐藏编辑入口，原 AI 状态与人工处理分开显示。记录包括改分理由、风险核验、限制处理和修订历史。重复创建、复核与定稿保留请求 key；遇到不确定网络结果时可以原请求重试。并发版本冲突提示刷新后核对，不覆盖其他复核者记录。

本地 token 仅在页面内存保存；刷新、退出需重新登录，没有 localStorage、sessionStorage 或 URL 凭据。上传与模型输出按文本节点插入，页面不执行材料内 HTML/脚本。静态资源来自本服务并纳入发布清单，CSP 禁止内联脚本、外部脚本和跨站连接。客户 SSO、正式会话策略和组织同步仍待集成，不能把本地验证账号当作生产身份系统。

界面验证使用独立合成目录与明确标注的报告 fixture；该 fixture 未调用模型，不是模型质量证据。真实模型证明沿用 v3 的 HTTP 全链报告。浏览器验证覆盖三类账号、上传、文本安全、引用定位、空档位图表、缺项/风险定稿拦截、定稿只读、员工切换，以及 1280px 和 390px 视口。具体结果与截图 hash 记录于 `evals/results/p3-web-verification.json`，截图保留在忽略的本地 artifacts 目录。

当前已提供 PDF 原页、Office 转换页、全屏结果图表和团队筛选分页；扫描 PDF 的辅助 OCR 仍需人工核对，生产部署待完成。用户已明确暂缓申诉及关联重新评估；现有人工复核中的补充材料引用保留。创建后的任务可由[本地持续调度服务](../../runtime/SERVICE.md)自动处理；服务需要单独启动并与 API 使用相同发布和数据库。网页不会用模拟结果替代失败或未开始的任务。

## v9 标准与结果交互

复核页在人工档位下提供 A–D 标准按钮。抽屉读取本次评估冻结的岗位、能力标准和模型版本，不查询最新目录替换历史标准。缺失档位明确提示，不能从抽屉选用；有权限且未定稿时可选择档位，处理方式自动区分确认、调整和独立人工判断。选择仅更新页面草稿，仍需填写理由与引用或观察依据，再点击保存。员工及已定稿记录只读。Escape 关闭并恢复焦点，退出和切换记录清空抽屉内容。

结果图表标签支持鼠标或键盘跳到相应维度/能力明细，显示 AI 依据、人工理由、观察依据、风险核验及引用。达到/低于推荐的计数只纳入有人工档位和推荐值的项目，材料不足不计为能力差距。未定稿结果明确标为复核进度。复核页默认折叠图表，先展示待处理能力和人工表单；需要时展开“查看能力结果与差距”。

本轮浏览器验证仍使用已有合成报告 fixture，没有执行模型、没有保存新的人工决定。完整 demo 对齐仍为部分完成，图表缩放/独立全屏检查器等交互尚未实现。核验记录见 [v9 UI 摘要](../../evals/results/p3-ui-alignment-v9-verification.json)。

## v10 PDF 页图

上传 PDF 或打开其原文后，显示原页、翻页、页码跳转及 150%/200% 放大。每个文本块的“在原件中定位”和 AI/人工引用定位都可进入准确页码，并为匹配的原文块画红框。页图遵循文件原有旋转；不旋转或改写原文件。无法精确匹配时明确提示，不画猜测的框。

页图与文本并列保留，复核仍使用服务端冻结引用。扫描页可以查看，但显示图片不等于已经 OCR；所有质量提示保留。Office 格式明确说明暂无原件页图，仍提供文本与结构路径及原件下载。页图资源只在当前页面内存中存在；关闭证据、切换员工和退出会释放，晚到的请求不会覆盖当前材料。

v10 浏览器核验使用虚构双页 PDF，第一页面有裁剪和 90° 旋转；报告明确标为未调用模型的 UI fixture。核验覆盖上传真实解析、页图、翻页、缩放、第二页引用、手机布局、清理与 Office 回退，不代表 OCR、Office 渲染或模型质量通过。

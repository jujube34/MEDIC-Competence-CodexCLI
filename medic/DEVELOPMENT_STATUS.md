## 2026-10-28 v17 后续开发

已将证据选择候选接入开发代码，并增加以下功能与修正：

- `assessment_submit_by_evidence_id` 与 v7 角色包：模型显式选择已读原文块，服务端展开原文/hash 后仍执行原有评分、授权、不可变结果和共享预算校验。旧接口的改写引文不自动修补。
- 网页 `/assessments/{id}/execution` 与 Agent 日志面板：按授权范围、游标分页显示任务进度、工具调用、校验拒绝、请求数和已报告用量；不返回原始事件 payload、密钥、材料全文或隐藏推理。断线可重新连接，退出和切换员工清理日志。
- macOS 不支持 `RLIMIT_AS`，原预览子进程因此启动失败。POSIX 解析/预览改用隔离进程组、CPU/墙钟限制和每50ms进程组 RSS 采样。采样不是瞬时硬内存上限，不等同于生产 OS 沙箱；超过限额或无法观察资源时终止进程组。
- POSIX 队列增加文件锁、进程组清理与父进程死亡监测。两个真实进程树测试通过，不代表所有平台故障或生产高可用验收。
- PostgreSQL 的 mailbox 参与者查询固定排序，避免技术重试时因行序不同改变上下文 hash。原有失败测试已复现并通过修复验证。
- 完整范围应用评估在创建时冻结2000请求、1800万tokens、并发3、2小时的技术预算；旧运行预算不变。小范围仍使用原80请求预算。
